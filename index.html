AI 답변 핵심 내용 요약

AI는 청소년 SNS 중독 개선 앱을 만들기 위해 안드로이드 기반 개발이 가장 현실적이라고 설명했다. Android Studio와 Kotlin을 사용하고, SNS 앱 사용 시간 측정에는 UsageStatsManager를, 알림 기능에는 NotificationManager를, 주기적 감시에는 WorkManager를 활용하는 방식을 제안했다.

또한 인터넷 속도 제한 기능은 일반 앱 권한만으로는 어렵고 VpnService 같은 고급 기술이 필요하므로, 초기 단계에서는 사용 시간 측정과 경고 알림 기능을 먼저 구현하는 것이 현실적이라고 조언했다.

2. 구현 방법 요약

AI가 제안한 기술 스택

Android Studio Kotlin UsageStatsManager NotificationManager WorkManager XML Layout

방법론

AI는 우리 팀의 기술 수준을 고려해 처음부터 모든 기능을 한 번에 구현하기보다, MVP, 즉 최소 기능 제품 방식으로 3단계에 걸쳐 개발하는 방법을 제안했다.

1단계: 사용 시간 측정

UsageStatsManager를 활용해 사용자의 SNS 앱 사용 시간을 측정한다. 이를 통해 청소년이 자신의 실제 사용 시간을 확인하고 과다 사용 여부를 인식할 수 있도록 한다.

2단계: 알림 및 행동 교정

NotificationManager와 WorkManager를 활용해 일정 사용 시간을 초과하면 경고 알림을 보내고, 주기적으로 자동 모니터링하는 기능을 추가한다.

3단계: 고급 제한 기능 확장

초기 아이디어였던 인터넷 속도 제한 기능은 VpnService와 같은 고급 기술이 필요하므로, 현재 팀 수준에서는 추후 확장 기능으로 설정한다.

주요 구현 단계

  1. Android Studio 설치 및 새 프로젝트 생성
  2. Kotlin 기반 기본 앱 구조 생성
  3. AndroidManifest.xml에 권한 설정
  4. UsageStatsManager를 통해 SNS 사용 시간 측정
  5. 사용 시간 기준 초과 시 알림 기능 구현
  6. WorkManager로 일정 시간마다 자동 검사
  7. UI 버튼으로 권한 허용 및 사용 시간 확인 기능 구현
  8. 추후 VPN 기반 속도 제한 기능 확장 검토

3. 팀 분석 및 의견

실현 가능성 평가

평가: 부분 가능

AI가 제안한 사용 시간 측정과 알림 기능은 Android Studio와 제공된 코드를 활용하면 구현 가능성이 높다. 그러나 인터넷 속도 제한 기능은 VpnService와 같은 고급 기술이 필요해 현재 팀 수준에서는 어렵다고 판단했다.

  • 일정 시간 초과 시 경고 알림

  • Android Studio 기반 MVP 구현

  • 속도 제한 대신 집중 모드 화면으로 대체 가능
  • 청소년이 이해하기 쉬운 UI로 단순화

4. AI 활용 소감

도움이 된 점

AI는 단순히 아이디어만 제시한 것이 아니라 실제 구현 가능한 기술 스택, 코드 구조, 개발 프로그램 사용법까지 단계별로 설명해주었다. 특히 우리 팀 수준에서 어떤 기능이 현실적이고 어떤 기능이 어려운지 구분해 준 점이 도움이 되었다.

한계로 느낀 점

제공된 코드가 그대로 완벽하게 작동하기 위해서는 Android Studio 환경 설정, 권한 문제 해결, 오류 수정 등 추가적인 이해가 필요했다. 또한 인터넷 속도 제한처럼 고급 기능은 AI 설명만으로 완전히 구현하기 어렵다고 느꼈다.

최종 정리

AI를 활용하면서 단순한 아이디어를 실제 구현 가능한 앱 구조로 구체화할 수 있었지만, 기술적 한계를 고려해 팀 수준에 맞게 기능을 조정하는 과정이 중요하다는 점을 알게 되었다.
