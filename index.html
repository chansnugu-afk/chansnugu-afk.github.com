SNS Control

청소년의 과도한 SNS 사용을 줄이기 위해 사용 시간을 측정하고, 일정 시간 이상 사용하면 알림과 제한 모드를 제공하는 디지털 습관 관리 앱입니다.

앱 기능 보기

문제 상황

청소년들은 SNS의 짧고 강한 자극에 반복적으로 노출되며 사용 시간을 조절하기 어려워지고 있습니다.

SNS는 즉각적인 보상과 끊임없는 콘텐츠 추천을 통해 사용자가 계속 화면을 보도록 유도합니다. 이로 인해 청소년은 학습 집중력 저하, 수면 부족, 자기조절 능력 약화 등의 문제를 겪을 수 있습니다. 따라서 단순히 사용을 금지하는 방식보다, 사용 시간을 스스로 인식하고 조절하도록 돕는 기술적 해결책이 필요합니다.

주요 기능

앱은 사용 시간 측정, 경고 알림, 제한 모드라는 세 가지 흐름으로 작동합니다.

1. SNS 사용 시간 측정

사용자가 인스타그램, 틱톡, 유튜브 등 주요 SNS 앱을 얼마나 사용했는지 확인합니다.

2. 사용 시간 알림

설정한 사용 시간을 넘으면 알림을 보내 사용자가 자신의 사용 습관을 인식하도록 돕습니다.

3. 제한 모드

일정 시간 이상 사용하면 집중 모드로 전환하고, 향후 VPN 기반 네트워크 지연 기능으로 확장할 수 있습니다.

4. 자기조절 유도

단순 차단이 아니라 쉬는 시간, 대체 활동, 목표 설정을 통해 자발적인 사용 감소를 유도합니다.

앱 작동 흐름

사용자가 앱을 실행한 뒤, SNS 사용 시간이 기준을 넘으면 단계적으로 경고가 이루어집니다.

STEP 1. 사용자가 SNS 앱 사용을 시작합니다.
STEP 2. 앱이 하루 사용 시간을 측정합니다.
STEP 3. 설정한 제한 시간을 넘으면 경고 알림을 보냅니다.
STEP 4. 반복 초과 시 집중 모드 또는 인터넷 지연 모드로 전환합니다.

기술 구현 방식

실제 앱 개발 단계에서는 Android Studio와 Kotlin을 활용합니다.

UsageStatsManager

안드로이드의 앱 사용 통계 기능을 이용하여 SNS 앱별 사용 시간을 측정합니다.

Notification

사용 시간이 기준치를 넘으면 사용자에게 경고 알림을 보냅니다.

WorkManager

앱이 꺼져 있어도 일정 시간마다 사용 시간을 확인하도록 백그라운드 작업을 수행합니다.

VpnService

고급 기능으로, 사용 시간이 초과되었을 때 네트워크 속도를 느리게 만드는 방식으로 확장할 수 있습니다.

기대 효과

이 앱은 청소년이 SNS 사용 시간을 직접 확인하고, 무의식적인 사용을 줄이도록 돕습니다. 단순한 강제 차단이 아니라 알림과 제한 모드를 통해 스스로 사용 습관을 조절하도록 유도한다는 점에서 의미가 있습니다. 또한 향후 인터넷 속도 지연 기능을 추가하면 SNS의 즉각적 보상 효과를 낮추어 중독 완화에 도움을 줄 수 있습니다.
